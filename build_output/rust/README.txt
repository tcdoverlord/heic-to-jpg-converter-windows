TCDOVERLORD HEIC TO JPG CONVERTER
Windows x64 Portable Package

HOW TO USE
1. Extract this ZIP to a folder.
2. Double-click HEIC-to-JPG-Converter.exe.
3. Select up to 20 HEIC/HEIF photos.
4. Choose a destination folder.
5. Set JPG quality and click Convert to JPG.

Your source photos are not intentionally modified or deleted.
Existing output files are preserved by choosing a different filename.

REQUIREMENTS
This package is intended for 64-bit Windows.
Test on a second Windows computer before redistributing.
The package includes DLLs found in the configured vcpkg triplet,
but this does not prove every native runtime or codec dependency
is included on every computer.
